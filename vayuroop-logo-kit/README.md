# VAYUROOP Logo Kit

## Files

### Primary (white background)
- `logo-full-{250,500,1000,2000,4000}w.png` — Full lockup (V diamond + VAYUROOP wordmark) at 5 widths
- `logo-mark-{16..1024}.png` — Mark (V diamond) square, for icons/app/favicons
- `logo-word-{250..2000}w.png` — Wordmark only
- `favicon.ico` — Multi-size favicon (16/32/48)
- `apple-touch-icon.png` — iOS home screen (180x180)
- `social-profile-{512,1024}.png` — Instagram/FB profile pic

### Transparent background
- `transparent/` folder — same assets on transparent background, for dark sites/overlays

### Print & production
- `for-print/logo-mark-black-2048.png` — Black mark for tags/labels
- `for-print/logo-mark-white-2048.png` — White mark (for black tees, neck labels)
- `for-print/logo-full-black-4000w.png` — Full lockup black
- `for-print/logo-full-white-4000w.png` — Full lockup white
- `for-print/logo-mark.svg` — Infinite-scale vector mark

## Usage guide

- **Website header / navbar**: `logo-full-500w.png` or `1000w.png` (white bg), or `transparent/logo-full-1000w.png`
- **Favicon**: drop `favicon.ico` in site root + add `<link rel="icon" href="/favicon.ico">`
- **Instagram/FB profile pic**: `social-profile-512.png`
- **T-shirt/hoodie chest print**: `for-print/logo-mark-white-2048.png` on black/dark fabric
- **Neck label / hang tag**: `for-print/logo-mark-black-2048.png`
- **Apple/iOS app icon**: `apple-touch-icon.png` (upload to site root)
